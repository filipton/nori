# Security

Please report a vulnerability privately, not in a public issue.

Use GitHub's private reporting: on [the repository](https://github.com/norifm/nori), open the Security tab
and choose **Report a vulnerability**. Say what you found, how to reproduce it and which client and
version it affects.
